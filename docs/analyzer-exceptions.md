# Scoped analyzer exceptions

The rules remain enabled across all five projects. Each exception below disables
only its reported source line, then restores the rule immediately. The source
comment states the technical reason; this inventory provides its exact scope.
The 70 scopes cover 71 diagnostic events because one rectangular-array field
has two CA1814 locations on the same line.

Validation covers renderer/packet faults, construction failures, disposal during
inspection, atomic-save rollback, bounded writer backpressure/failure, retention
and native ABI/profile/face equivalence. The five long historical algorithms
remain in the test-only reference engine; production method length remains
enabled. The two constructor exceptions retain immutable native layout mapping.
Synchronous bridges keep their engine/GL owner thread or their CPU sample thread;
their independent worker does not capture that synchronization context. Exact-one
assertions continue to reject duplicate files, records and metadata.

The two HLQ001 scopes cover locals accessed only through dictionary indexers,
never enumerated. The remaining CA2000 scope covers an unconditional finally
disposal and a leave-open BinaryReader. Atomic Interlocked.Exchange ownership
release explains the reference renderer's CA2213 scope.
